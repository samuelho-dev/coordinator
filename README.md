# `coordinator`: one-page implementation contract

**Boundary and flow.** Separate private pnpm+Effect project, never a creativetoolkits feature. Preserve omp task/worker/Agent Hub IDs and states; ATC is communication discipline, not another participant/assignment engine. Pi/omp plugin ↔ private Tailnet broker ↔ macOS/Linux runner ↔ owned JSONL RPC child. GitHub and human review → independent task evidence; consented host journals → local spool → owner archive. Plugin owns commands/session identity/delivery, broker owns routing/ledger/evidence, runner owns slots/acceptance/worktrees/children, host owns native journal. No automatic apply, merge or deploy.

**Runtime and identity.** Lockfile pins compatible Effect, platform-node and sql-sqlite-node 4.0.1. Schema validates bounded RPC; broker-local SQLite contains ledger and PersistedQueue dispatch, never network-shared. Node ≥22.16 must provide SQLite online backup; deployment uses Node24 and installer probes runtime. Canonical selected Git remote routes, never authorizes; ambiguous remotes fail. Owner enrollment pins inspected GitHub repository IDs. Private signed image carries exact-SHA Git objects in a credential-free bundle; CI read credentials never gate dispatch or bootstrap.

**Peer first.** Authenticated plugin enrolls machine/host/session/incarnation and heartbeats. Restarted broker treats saved sessions as unverified until fresh heartbeat. Offer worker-addressed work only to a verified-live matching repo/worker binding with active polling. Receipt is not acceptance. Decline, unavailable/expired offer or explicit bypass permits runner dispatch; never assume saved sessions are live or use an offline mailbox. Advertised fresh load guides choice; runner independently checks capacity.

**Durable dispatch.** Client task ID and approved bounded request enter unique SQLite ledger as QUEUED before queue offer; recovery repairs missing offers. Same ID/fingerprint is idempotent; changed material conflicts. Persist ASSIGNING/runner before acceptTask. Runner verifies broker-owned task/fingerprint and commits acceptance, launch material and isolated allowlisted worktree path before reply/launch; only durable acceptance acknowledges queue claim. Full/not-accepted stays queued without retry exhaustion. Timeout reconciles that runner journal; unknown blocks reassignment. Never automatically rerun accepted work. Restart resumes accepted-but-not-launched work; uncertain child/prompt remains held, retaining occupied capacity where needed. Obsolete reports cannot starve other rows.

**Owned child and follow.** Runner supervises its Pi/omp RPC child in the exact repo/ref/SHA worktree. Authorized coordinator proxy reaches that child, not arbitrary native sessions. Coordinator/broker exit preserves runner work; another coordinator queries result/status and attaches while channel lives. Runner loss may destroy stdio reattachment: inspect journal/process, never infer completion or replay. Persist only bounded child status/identity metadata, not message/thinking/tool content or diagnostics. Native journals remain host-owned. Execution completion never implies CI, deployment or approval.

**Addressed release.** Existing task/worker IDs, session/incarnation, message/revision, repo/ref/SHA, scope, restrictions, expected evidence and deadline are read back; coordinator confirms current matching ready revision before substantive prompt. Wrong ref requires correction/new readback; unable/clarify/hold carry reason, hold includes next-check. Confirmed release cannot be reset by changing address/readback/instruction. Handoff names old/new sessions and revision, reconciles old acceptance, requires matching new worker and fresh readback/confirmation. Live or release-uncertain native/runner work blocks handoff until known terminal result. Already-running work is not retroactively gated. Later approved native instructions use a new message/revision, never replay immutable runner launch prompt.

**Peer durability.** Commit bounded payload/message/incarnation/short TTL before sender ack; replay unacknowledged delivery only to same incarnation. Recipient durably deduplicates before acknowledging handling. Delete on ack, stop or TTL; reject new sends offline. Lost ack permits repeated delivery, not exactly-once effects.

**Evidence.** Bind inspected repo ID, intended ref, full tested SHA and required lanes. Read-only GitHub polling records exact run/attempt/jobs; newest relevant attempt must successfully complete every lane. Missing/API-loss/pending/skipped/cancelled cannot borrow old green; PR merge refs require authenticated PR association/current merge SHA, never source-head substitution. Display latest local, CI, deployment environment/SHA and authenticated human review with provenance/time separately from runner result. SHA changes stale observations; same-SHA ref/lane policy changes stale CI. Repeated polls retain independent categories. Observations never authorize execution or change omp task state; unavailable scoped credential means unknown, never broad PAT fallback.

**Consented archive.** Explicit session/every-participant consent precedes complete-line, branch-aware scanning. Capture only entry IDs/parents/type/role; omit content/tools/thinking/paths/credentials before bounded durable spool. Cannot reconstruct readable conversation. Append asynchronously/idempotently by owner/session/entry/digest; record rewrite/overflow/missing/ephemeral/unlinked/content-omitted gaps. No model logging tool or turn-blocking network call. Opt-out revokes before spool/row deletion; participant revocation removes enrollment/archive. Archive retention differs from peer TTL. Online snapshots erase archive/all consent rows before backed volume; raw/temp data excluded, sanitized copies expire.

**Security and acceptance.** TLS plus enrollment/operation authorization on every call, reply/report/attach; private Tailnet, never Funnel. Restrict paths/launchers/payloads/permissions, rotate credentials, redact logs; archive writer append-only. Runner outbound enrollment is health/report-only; broker control is distinct, raw broker-only/hash runner-only, with ledger-bound acceptance/release. Broker plaintext is not E2EE. Install backed supervised broker, durable runners and per-session plugins; exercise real sockets, duplicates/restarts/ambiguous acceptance, peer replay/expiry, addressed gates, independent evidence, surviving coordinator exit, unauthorized failures and persistent archive deletion/gaps.

**Install/check.** `pnpm install --frozen-lockfile`; scripts `check`, `test`, `smoke`, `smoke:hosts`, `install:host -- --help`; private0600 configs/tokens, native package registration OR explicit `-e` (never both), Linux user-systemd/Kubernetes or Mac GUI-launchd; Homelab ai-dev-env PR/CI/ArgoCD only. Linux omp18.6.1/Pi1.0.4 runtime-proved; Pi0.84.2 source-checked, not Mac proof.
