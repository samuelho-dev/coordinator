# `coordinator`: one-page implementation contract

**Boundary and flow.** Private pnpm+Effect project, never a creativetoolkits feature. Carry distinct Effect-branded IDs through API/storage/native boundaries; unchanged primitive wires, no Agent Hub API. ATC is communication discipline, not another participant engine. Pi/omp plugin ↔ private Tailnet broker ↔ owned runner/native MCP child. GitHub/review → independent evidence; consented journals → spool → owner archive. Plugin owns identity/delivery, broker routing/ledger/evidence, runner slots/children, host journals. No automatic apply/merge/deploy.

**Runtime.** Effect pinned to pkg.pr.new d6082a25a3779f7e2abba2787323d5d9c7e1d24a; platform-node/sql-sqlite-node 4.0.2. `Context.Service`/scoped layers own I/O. `contracts.ts` owns 78 `Commands`: targets, descriptions, schemas, executions; IDs/default MCP methods derive from keys, overrides only for differing wires. Native Schema validates/encodes directly, no serializer wrappers; `http.ts` MCP boundary; `main.ts broker|runner`, `.ts` imports. Broker/runner Effect MCP serves `/mcp` (2026-07-28/2025-11-25); its official client 2.3.1 uses Effect HTTP, while installed-plugin native control uses official Streamable HTTP. Per-request bearer/Origin checks, structured-only results and typed errors, exact UTF-8 bounds; no `/rpc` or OAuth/resume contract. Plugin transport-session termination is not host settlement. Effect SHA/random, WebCrypto HMAC/native verification; no NodeCrypto. SQLite WAL/FULL/migration ledgers/PersistedQueue, never network-shared; unstable MCP/SQL APIs pinned. Node≥22.16 online backup, Node24 image/installer SQL probe. Git routing never authorizes; ambiguity fails, repository IDs inspected. Signed exact-SHA credential-free bundle bootstraps without CI credentials.

**Peer first.** Plugin enrolls machine/host/session/incarnation plus native session ID as worker. Broker restart requires fresh heartbeat. Only verified-live, actively polling, matching repo/worker gets offers. Receipt is not acceptance. Decline, unavailable/expired offer or explicit bypass permits runner dispatch; no offline mailbox. Fresh load guides choice; runner independently enforces capacity. Address/readback/confirmation/release require accepted bound peer ownership; runner-owned work never releases to stale peers.

**Durable dispatch.** Approved bounded request/task ID enters unique QUEUED ledger before queue offer; recovery repairs missing offers. Same ID/fingerprint is idempotent; changed material conflicts. Persist ASSIGNING/runner before acceptTask. Runner rechecks authoritative assignment/fingerprint/deadline after Git/transaction waits, then commits acceptance/material/worktree before reply/launch; only durable acceptance acknowledges queue claim. Pending admission journals return unknown/503, never not-accepted. Full/not-accepted stays queued without exhaustion. Timeout reconciles that runner; unknown blocks reassignment. Never rerun accepted work automatically. Restart resumes accepted-but-unlaunched work; uncertain child/prompt stays held with occupied capacity. Obsolete reports cannot starve others.

Kernel-held Linux `flock` owns journals, never persisted PIDs: duplicates fail closed, death releases ownership across PID-one/container restarts, and helper loss stops serving without later journal writes. Util-linux supplies `flock`/`setpriv`; GNU `env --chdir` preserves effective supervisor capabilities before dropping child privileges.

**Owned child and isolation.** Trusted supervisor UID1000 has only CHOWN/DAC_OVERRIDE/KILL/SETUID/SETGID/SETPCAP; KILL supervises different-UID children. Each child uses a distinct reserved UID, zero capabilities/supplementary groups, NoNewPrivs, separate standalone repo/session/model HOME and model-only environment. Private enrollment/control/journal/parent environment/sibling work are inaccessible. Reserve non-overlapping million-UID ranges; retain acceptance rows. Model seed excludes histories/symlinks. Authorized proxy targets owned exact repo/ref/SHA child, not arbitrary sessions. Coordinator/broker exit preserves runner work; attach while channel lives. Lost stdio cannot imply completion/replay. Failed acquisition stays HELD; release capacity only after scoped physical closure. SDK deadlines/owner mismatches remain typed errors. Persist bounded identity/status metadata, never messages/thinking/tools/diagnostics. Native journals remain private host data.

**Addressed release.** Read back task/current worker, session/incarnation, message/revision, repo/ref/SHA, scope, restrictions, evidence and deadline; coordinator confirms current matching ready revision before prompt. Wrong ref needs correction/new readback; unable/clarify/hold carry reason, hold includes next-check. Confirmed release cannot reset through address/readback/instruction changes. Explicit old/new-session handoff reconciles acceptance, binds actual new worker and requires fresh readback/confirmation. Live/uncertain releases block handoff until known terminal outcome. Existing running work is not retroactively gated. Later approved native instruction needs new message/revision; immutable runner launch prompt never replays.

**Peer durability.** Commit bounded message/incarnation/short TTL before ack; replay unacknowledged delivery only to same incarnation. Recipient durably deduplicates before handling ack. Delete on ack/stop/TTL; offline sends fail. Lost ack allows redelivery, not exactly-once effects.

**Evidence.** Inspected repo ID, ref, full tested SHA and lanes bind read-only GitHub run/attempt/jobs. Newest relevant attempt must successfully complete every lane. Missing/API-loss/pending/skipped/cancelled cannot borrow old green; merge refs require authenticated current PR merge SHA, never source-head substitution. Latest local, CI, deployment environment/SHA and authenticated review retain separate provenance/time. SHA changes stale observations; same-SHA ref/lane changes stale CI. Polls preserve categories; 15s bounds headers/body/decode. Completion is not CI/deployment/approval. Evidence never authorizes execution/changes native task state; missing scoped credential means unknown, not broad PAT fallback.

**Consented archive.** Explicit session/every-participant consent precedes complete-line branch-aware scanning. `HostJournalEntry` projects metadata through one Effect schema; Effect Graph resolves parents across all complete lines, including later branches, and missing or incomplete parents record `unlinked`. Only entry IDs/parents/type/role enter bounded spool; content/tools/thinking/paths/credentials omitted, conversations unreconstructable. Async owner/session/entry/digest append is idempotent; record rewrite/overflow/missing/ephemeral/unlinked/content-omitted gaps. No logging model tool or turn-blocking network. Opt-out revokes before spool/row deletion; participant revocation removes enrollment/archive. Archive retention differs from peer TTL. Online snapshots erase archive/all-consent rows and VACUUM before dedicated-bucket SigV4 streaming. `objectBackup`: enforced-HTTPS/region/bucket/private0600 credential files, no 1Password API; Kubernetes Secret/other managers require no application change. Local/object expiry share retention; restore exclusive. Raw/temp/native/enrollment excluded. Unconfigured bucket/key means no durable-backup claim.

**Security/install/check.** TLS/enrollment/operation authorization, private Tailnet never Funnel; restricted paths/launchers/payloads, private0600 configs/tokens, rotation/redaction, append-only archive writer. Runner enrollment health/report-only; distinct control raw broker-only/hash runner-only, ledger-bound acceptance/release. Broker plaintext not E2EE. `pnpm install --frozen-lockfile`; `check` ([native-tsgo/Effect-lint](https://github.com/Effect-TS/tsgo#lsp-based-linter); warnings-visible, errors-fatal), `test`, `smoke`, `smoke:hosts`, `install:host --help`. `smoke:backup`: private `COORDINATOR_BACKUP_SMOKE_CONFIG`, loopback proof bucket. Native-user `--plugin-only`, root Linux `--runner-only`, trusted release/dedicated non-login account; Kubernetes bounded bootstrap. Registration/`-e` exclusive. Mac plugin-only. Homelab ai-dev-env PR/CI/ArgoCD verifies ESO/TLS/health/durability/gates/backup; no imperative deploys.

**Integration and deployment.** Private `main` integration of the supported public plugin controls and broker is authorized; commit follows the focused local gate and exact-commit hosted CI validates the pushed source. This is not model whole-run or Ghostty visual acceptance. Mac Ghostty verification is user-owned, Rex remains deferred, and infrastructure/image deployment is not part of this source integration. Maintained-host forks, SDK rewrites and native host upgrades are superseded, not done; their source/evidence is retained, not a plugin deliverable. No global binary replacement or automatic apply/merge/deploy. Kyverno-compatible legacy Cosign signatures/SLSA-v1 attestations and admission remain enforced. CI stages code outside private homes; generated `dist/` artifacts are rebuilt, not committed.

**Public plugin control.** `pnpm native:build` compiles the native package and bundles the two public extensions with their existing dependencies. Both host manifests load `dist/plugins/plugin.js` and `dist/plugins/native-plugin.js`; the runner launches the installed CLI with `--mode rpc --no-extensions -e dist/plugins/native-plugin.js`. Bundling keeps each extension on one private Effect runtime: the stock OMP source loader otherwise splits Effect's request-header state and loses the MCP session header. HTTP catalog cursors bind to the validated MCP session header, not the per-POST RPC client ID; `test/native-mcp-byte-limits.test.ts` exercises real multi-page discovery, byte bounds and foreign-session rejection. STDIO retains its client fence. Native RPC stdout/stderr are drained privately, never parsed as MCP. `COORDINATOR_NATIVE_CONFIG` names a private configuration containing `host`, `tokenFile` and `endpointFile`; the plugin atomically publishes its authenticated loopback `/mcp` endpoint and actual session binding. Only implemented public capabilities are advertised: state, messages, entries, abort, steering, follow-up and public extension command execution. HTTP peers without resource push use scoped retained-journal polling, never inferred settlement from idle. Native busy/queue fields unavailable to this adapter are `null` or omitted, never fake idle defaults. Docker and CI stage compiled `dist/plugins` artifacts and make staged trusted code readable to distinct-UID children; CI creates its `0700` private HOME afterward, without making tokens or transcripts public.

**Connect from Ghostty.** Build this checkout with `pnpm install --frozen-lockfile && pnpm native:build`. Set `COORDINATOR_CONFIG` to the absolute private0600 `PluginConfig` JSON (`brokerUrl`, `tokenFile`, `machineId`, `stateDirectory`, `host:"omp"`). For native controls also set `COORDINATOR_NATIVE_CONFIG` to an absolute private0600 `NativePluginConfig` JSON (`host:"omp"`, canonical private `tokenFile`, `endpointFile` in a0700 directory). Use the existing stock OMP binary from Ghostty in the target Git worktree: `omp --no-extensions -e /absolute/coordinator/dist/plugins/plugin.js -e /absolute/coordinator/dist/plugins/native-plugin.js`; do not also register the same package globally. `/coordinator identity`, `/coordinator inbox` and `/coordinator help` expose the actual session/broker path. OSC7501 is emitted only on root-agent TUI stdout; this Linux PTY path is not Mac pixel proof.

**Public-hook prerequisite.** Upstream must acknowledge the caller's `submissionId` with `started|queued|handled` and stable session/incarnation/run correlation (`handled` has no run), then publish exactly one correlated final `completed|aborted|error` outcome after retries, compaction, async wake, continuation and cancellation finish. Installed Pi 1.0.4 and OMP 18.6.1 both expose `sendUserMessage(...): void`, not admission. Pi's final `agent_settled` is only `{type}`; `agent_before_settle.outcome` is tentative until later awaited handlers and cancellation finish. OMP's `agent_end` exposes messages and optional `willContinue`, while `session_stop` can request another continuation; its public lifecycle mirror omits internal terminal/async-ownership fields. Neither supplies the required correlated final result. A local plugin journal or activity UUID cannot manufacture missing host facts. Until both public contracts exist, `native.prompt` is not advertised; the runner keeps an inspectable `HELD` child without a prompt intent or automatic send, and peer delivery records one durable attempt then remains `HELD` until explicit outcome reporting. OSC 7501 stays on root-agent TTY/TUI stdout only; uncertain final status is cleared, never manufactured as done/error.

All seven are advertised; successful steer/follow-up delivery is not claimed because idle public `sendUserMessage` can start a provider turn.
