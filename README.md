# `coordinator`: one-page implementation contract

**Boundary and flow.** Separate private pnpm+Effect project, never a creativetoolkits feature. Carry caller task IDs and actual native-session worker IDs, not an unavailable Agent Hub API. ATC is communication discipline, not another participant engine. Pi/omp plugin ↔ private Tailnet broker ↔ owned runner/JSONL RPC child. GitHub/review → independent evidence; consented journals → spool → owner archive. Plugin owns identity/delivery, broker routing/ledger/evidence, runner slots/children, host journals. No automatic apply, merge or deploy.

**Runtime.** Effect/platform-node/sql-sqlite-node 4.0.1; `Context.Service`/scoped layers own I/O. `contracts.ts` owns 78 `Commands`: targets, descriptions, schemas, executions; `http.ts` sole codec/MCP boundary; `main.ts broker|runner`, `.ts` imports. Native Effect MCP serves `/mcp` (2026-07-28/2025-11-25); official client 2.3.1 uses Effect HTTP. Per-request bearer/Origin checks, structured-only results; no `/rpc`, OAuth/resume/termination claims. Effect SHA/random, WebCrypto HMAC/native verification; no NodeCrypto. SQLite WAL/FULL/migration ledgers/PersistedQueue, never network-shared; unstable MCP/SQL APIs pinned. Node≥22.16 online backup, Node24 image/installer SQL probe. Git routing never authorizes; ambiguity fails, repository IDs inspected. Signed exact-SHA credential-free bundle bootstraps without CI credentials.

**Peer first.** Plugin enrolls machine/host/session/incarnation plus native session ID as worker. Broker restart requires fresh heartbeat. Only verified-live, actively polling, matching repo/worker gets offers. Receipt is not acceptance. Decline, unavailable/expired offer or explicit bypass permits runner dispatch; no offline mailbox. Fresh load guides choice; runner independently enforces capacity. Address/readback/confirmation/release require accepted bound peer ownership; runner-owned work never releases to stale peers.

**Durable dispatch.** Approved bounded request/task ID enters unique QUEUED ledger before queue offer; recovery repairs missing offers. Same ID/fingerprint is idempotent; changed material conflicts. Persist ASSIGNING/runner before acceptTask. Runner rechecks authoritative assignment/fingerprint/deadline after Git inspection, then commits acceptance/material/worktree before reply/launch; only durable acceptance acknowledges queue claim. Pending admission journals return unknown/503, never not-accepted. Full/not-accepted stays queued without exhaustion. Timeout reconciles that runner; unknown blocks reassignment. Never rerun accepted work automatically. Restart resumes accepted-but-unlaunched work; uncertain child/prompt stays held with occupied capacity. Obsolete reports cannot starve others.

Journal ownership uses scoped kernel-held Linux `flock`, not a persisted PID: duplicates fail closed, death releases ownership across PID-one/container restarts, and helper loss stops serving without later journal writes. Util-linux supplies `flock`/`setpriv`; GNU `env --chdir` preserves effective supervisor capabilities before dropping child privileges.

**Owned child and isolation.** Trusted supervisor UID1000 has only CHOWN/DAC_OVERRIDE/KILL/SETUID/SETGID/SETPCAP; KILL supervises different-UID children. Each child uses a distinct reserved UID, zero capabilities/supplementary groups, NoNewPrivs, separate standalone repo/session/model HOME and model-only environment. Private enrollment/control/journal/parent environment/sibling work are inaccessible. Reserve non-overlapping million-UID ranges; retain acceptance rows. Model seed excludes histories/symlinks. Authorized proxy targets owned exact repo/ref/SHA child, not arbitrary sessions. Coordinator/broker exit preserves runner work; attach while channel lives. Lost stdio cannot imply completion/replay. Persist bounded identity/status metadata, never messages/thinking/tools/diagnostics. Native journals remain private host data.

**Addressed release.** Read back task/current worker, session/incarnation, message/revision, repo/ref/SHA, scope, restrictions, evidence and deadline; coordinator confirms current matching ready revision before prompt. Wrong ref needs correction/new readback; unable/clarify/hold carry reason, hold includes next-check. Confirmed release cannot reset through address/readback/instruction changes. Explicit old/new-session handoff reconciles acceptance, binds actual new worker and requires fresh readback/confirmation. Live/uncertain releases block handoff until known terminal outcome. Existing running work is not retroactively gated. Later approved native instruction needs new message/revision; immutable runner launch prompt never replays.

**Peer durability.** Commit bounded message/incarnation/short TTL before ack; replay unacknowledged delivery only to same incarnation. Recipient durably deduplicates before handling ack. Delete on ack/stop/TTL; offline sends fail. Lost ack allows redelivery, not exactly-once effects.

**Evidence.** Inspected repo ID, ref, full tested SHA and lanes bind read-only GitHub run/attempt/jobs. Newest relevant attempt must successfully complete every lane. Missing/API-loss/pending/skipped/cancelled cannot borrow old green; merge refs require authenticated current PR merge SHA, never source-head substitution. Latest local, CI, deployment environment/SHA and authenticated review retain separate provenance/time. SHA changes stale observations; same-SHA ref/lane changes stale CI. Polls preserve independent categories. Execution completion implies neither CI, deployment nor approval. Evidence never authorizes execution/changes native task state; missing scoped credential means unknown, not broad PAT fallback.

**Consented archive.** Explicit session/every-participant consent precedes complete-line branch-aware scanning. Only entry IDs/parents/type/role enter bounded spool; content/tools/thinking/paths/credentials omitted, conversations unreconstructable. Async owner/session/entry/digest append is idempotent; record rewrite/overflow/missing/ephemeral/unlinked/content-omitted gaps. No logging model tool or turn-blocking network. Opt-out revokes before spool/row deletion; participant revocation removes enrollment/archive. Archive retention differs from peer TTL. Online snapshots erase archive/all-consent rows and VACUUM before dedicated-bucket SigV4 streaming. `objectBackup`: TLS/region/bucket/private0600 credential files, not a 1Password API; Kubernetes Secret/another secret manager requires no application change. Local/object expiry share retention; restore exclusive. Raw/temp/native/enrollment excluded. Unconfigured bucket/key means no durable-backup claim.

**Security/install/check.** TLS/enrollment/operation authorization, private Tailnet never Funnel; restricted paths/launchers/payloads, private0600 configs/tokens, rotation/redaction, append-only archive writer. Runner enrollment health/report-only; distinct control raw broker-only/hash runner-only, ledger-bound acceptance/release. Broker plaintext not E2EE. `pnpm install --frozen-lockfile`; `check` ([native-tsgo/Effect-lint](https://github.com/Effect-TS/tsgo#lsp-based-linter); warnings visible, errors fatal), `test`, `smoke`, `smoke:hosts`, `install:host --help`. `smoke:backup`: private `COORDINATOR_BACKUP_SMOKE_CONFIG`, loopback proof bucket. Native-user `--plugin-only`, root Linux `--runner-only`, trusted release/dedicated non-login account; Kubernetes bounded bootstrap. Registration OR `-e`, never both. Mac runner unsupported/plugin-only; Mac OMP18.6.1/Pi0.84.2 plugins exercised before MCP cutover. Linux smoke uses OMP18.6.1/Pi1.0.4, no model turns. Homelab ai-dev-env PR/CI/ArgoCD verifies ESO/TLS/health/durability/gates/backup; no imperative application deployment.

**Publication.** Signatures and SLSA-v1 attestations use the platform's Kyverno-compatible legacy Cosign storage; admission stays enforced.
